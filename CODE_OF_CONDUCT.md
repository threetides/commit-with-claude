# Code of Conduct

Be kind, be constructive, assume good faith. Criticise code, not people. Harassment of any kind is not tolerated.

If someone is making the project unpleasant for others, contact the maintainer through the publisher profile and it will be dealt with privately.

This is a condensed statement of the principles in the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), which applies in full.
